# fitdata.app — Claude Code

Static website for FitData and Matchday XI (DE/EN), served by GitHub Pages from `main`.
**Every push to `main` publishes.** Commit locally, push only after the owner's explicit go.

- Preview: `python3 -m http.server 8765 --bind 127.0.0.1`, then check phone (375 px) and desktop width, both languages.
- Before a commit: `python3 -B scripts/verify_site.py`, `node --check assets/nav.js`, `node --check analytics-consent.js`.
- Design rules: the global `design-review` skill, section "Websites". Accent as text uses `--accent-text`; hover effects only under `@media (hover: hover) and (pointer: fine)`; motion only on `transform`/`opacity`.
- Analytics load only after consent and only on fitdata.app; Matchday pages carry no analytics. Don't add third-party requests that the privacy pages don't name.
- Blog pages are generated by `scripts/build_blog.py`; change the template, not the output.
- Screenshots come from the apps' current builds; record their source in `sources.json` (Matchday) as the README describes.
